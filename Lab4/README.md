# Лабораторна робота №4: Синтез вербальної інформації

Лабораторна робота з дисципліни **«Цифрова обробка інформації» (ЦОІ)**.

## Мета роботи
Ознайомитися з поняттям аудіосистем. Освоїти процес створення аудіосистеми на прикладі голосового помічника із використанням мови програмування Python.

---

## Основні формули

| № | Формула | Призначення |
|---|---------|-------------|
| (1) | $e[n] = x[n] - Q[x[n]]$ | Шум квантування |
| (2) | $ВСШ = 6B - 7{,}2$ дБ | Відношення сигнал-шум при рівномірному квантуванні |
| (3) | $y = \ln(1 + \mu \|x\|) / \ln(1 + \mu) \cdot \text{sgn}(x)$ | μ-закон компресії |

## Встановлення та запуск

### 1. Створення віртуального середовища

**Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows (PowerShell):**
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

### 2. Встановлення залежностей
```bash
pip install -r requirements.txt
```

### 3. Запуск програми
```bash
python lab4.py
```

Програма пропонує два режими:
- **1** — генерація демонстраційних аудіофайлів (без інтерактиву)
- **2** — інтерактивний голосовий помічник

### 4. Команди голосового помічника

| Команда | Відповідь |
|---------|-----------|
| привіт | Вітання |
| час | Поточний час |
| дата | Поточна дата |
| як справи | Відповідь про стан |
| допомога | Список команд |
| бувай | Завершення роботи |
