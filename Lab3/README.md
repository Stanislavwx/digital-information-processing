Лабораторна робота з дисципліни **«Цифрова обробка інформації» (ЦОІ)**.

## Мета роботи
Ознайомитися з принципами кореляції та автокореляції сигналів. Освоїти обчислення взаємної кореляції, нормованого коефіцієнта кореляції та автокореляційної функції.

---

## Основні формули

| № | Формула | Призначення |
|---|---------|-------------|
| (2) | $r_{12} = \frac{1}{N} \sum_{n=0}^{N-1} x_1(n) \cdot x_2(n)$ | Взаємна кореляція |
| (3) | $r_{12}(j) = \frac{1}{N} \sum_{n=0}^{N-1} x_1(n) \cdot x_2(n+j)$ | Кореляція із затримкою |
| (5) | $\rho_{12}(j) = \frac{r_{12}(j)}{\frac{1}{N}\sqrt{\sum x_1^2(n) \times \sum x_2^2(n)}}$ | Нормований коефіцієнт |
| (6) | $r_{11}(j) = \frac{1}{N} \sum_{n=0}^{N-1} x_1(n) \cdot x_1(n+j)$ | Автокореляція |
| (7) | $r_{11}(0) = \frac{1}{N} \sum_{n=0}^{N-1} x_1^2(n) = S$ | Нормована енергія |

## Встановлення та запуск

### 1. Створення віртуального середовища

**Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows (PowerShell):**
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

```bash
pip install -r requirements.txt
```

```bash

```
