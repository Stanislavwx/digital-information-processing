# Лабораторна робота №1: Детерміновані сигнали для обробки інформації

Лабораторна робота з дисципліни **«Цифрова обробка інформації» (ЦОІ)**.

## Мета роботи
Вивчити математичні моделі базових детермінованих сигналів та освоїти методи їх програмного моделювання у часовій області й аналітичного розрахунку відповідних Фур'є-образів.

---

## Теоретична зведена таблиця сигналів

| № | Сигнал | Часова область $s(t)$ | Фур'є-образ $S(f)$ | Застосування в інформаційних системах |
|---|---|---|---|---|
| 1 | **Косинусоїдальний** | $\cos(\pi t)$ | $\frac{1}{2}\delta(f+0.5) + \frac{1}{2}\delta(f-0.5)$ | Високочастотні носії в радіозв'язку, ортогональний базис Фур'є |
| 2 | **Синусоїдальний** | $\sin(\pi t)$ | $\frac{i}{2}\delta(f+0.5) - \frac{i}{2}\delta(f-0.5)$ | Квадратурні складові (QAM, IQ-модуляція) |
| 3 | **$\delta$-функція Дірака** | $\delta(t)$ | $1$ | Зняття імпульсної характеристики LTI-систем, тестування фільтрів |
| 4 | **Прямокутний імпульс** | $\text{rect}(t/T)$ | $T \cdot \text{sinc}(T f)$ | Цифрові строби, бінарні біти PCM, часові вікна |
| 5 | **Функція відліків** | $\text{sinc}(t)$ | $\text{rect}(f)$ | Інтерполяція Котельникова-Шеннона, ідеальний ФНЧ |
| 6 | **Функція signum** | $\text{sgn}(t)$ | $\frac{1}{j \pi f} = -j\frac{1}{\pi f}$ | Фазова маніпуляція (BPSK), перетворення Гільберта, компаратори |
| 7 | **Трикутний імпульс** | $\Lambda(t/T)$ | $T \cdot \text{sinc}^2(T f)$ | Згладжувальні вікна (Бартлетта), ШІМ-генератори |

## Встановлення та запуск

Робота виконується у віртуальному середовищі `venv`:

### 1. Створення та активація віртуального середовища

**Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows (PowerShell):**
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

### 2. Встановлення залежностей
```bash
pip install -r requirements.txt
```

### 3. Запуск програми
Після активації `venv` уся лабораторна робота запускається однією командою:
```bash
python lab1.py
```

Програма послідовно:
1. Виконує **Завдання 2** (код з додатку методички: прямокутний сигнал та sinc-функція).
2. Виконує **Завдання 3** (моделювання всіх одномірних сигналів та розрахунок їх аналітичних Фур'є-образів).
3. Зберігає всі графіки у папку `figures/` та відкриває графічні вікна.

### 4. Деактивація середовища (після завершення роботи)
```bash
deactivate
```

## Основні результати та висновки

1. **Принцип невизначеності**: чим коротший сигнал у часі (аж до $\delta(t)$), тим ширший його спектр (рівномірний білий спектр для дельта-функції).
2. **Дуальність перетворення Фур'є**: прямокутна форма сигналу у часі породжує спектр $\text{sinc}(f)$, а функція відліків $\text{sinc}(t)$ у часі формує прямокутний спектр $\text{rect}(f)$ (ідеальний частотний фільтр).
3. **Вплив гладкості**: стрибкоподібні розриви прямокутного сигналу зумовлюють повільне спадання спектра $\sim 1/f$. Неперервна трикутна функція $\Lambda(t)$ забезпечує прискорене спадання бічних пелюсток $\sim 1/f^2$, що мінімізує міжканальні завади при фільтрації.
